# Vite Vendu

Appli web (PWA) pour préparer rapidement ses annonces Vinted depuis l'iPhone :
photos, note vocale analysée par Gemini, préremplissage depuis les photos,
annonce complète avec prix conseillé, retouche photo et visuel porté via l'appli Gemini.

- Aucune donnée n'est stockée sur ce dépôt : articles et photos restent sur le téléphone, la clé Gemini aussi.
- Rien n'est publié automatiquement sur Vinted (copier-coller).
- Détourage : [@imgly/background-removal](https://github.com/imgly/background-removal-js) (AGPL-3.0), chargé depuis jsDelivr.
